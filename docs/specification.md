# FileManager3仕様書

この文書は仕様書の入口です。保守時の手順とコードの責務は [保守ガイド](00_maintenance.md)、機能の詳細は各章を参照してください。

## 現行バージョン

`0.0.2026091801`（2026-09-18）

## 1. 概要
案件を中心に、書類・写真・動画・メモ・販売店・担当者・ユーザーを管理するLAN対応Webアプリケーション。

## 2. 主要機能
- **認証**: セッションCookie、パスキー、Google OAuth対応（Basic認証不使用、無操作1時間で自動ログアウト、操作中はセッションを延長、5回失敗で15分ロック）。Google初回ユーザーはmember権限で作成する。
- **日時**: 画面および画面表示用APIの日時は日本時間（JST、UTC+9）で扱い、データベースにはUTCで保存する。
- **案件検索**: 単一テキストボックスによる横断検索（スペース区切りの複数キーワードAND検索対応）。モバイルの検索結果は案件名も他項目と同じラベル左・内容右で表示し、フリガナは案件名の内容の下に表示する。行間と余白を詰めて一覧性を高める。
- **案件管理**: 登録・編集・論理削除・復元、管理者による削除済み案件の物理削除、ソート（案件番号・案件名・更新日時）
- **ファイル管理**: 書類・写真・動画（MP4/M4V/MOV/WebM/OGV）のアップロード・閲覧・移動・版管理（書類には画像・動画も保存可能、書類画像はWebP変換して写真と同じプレビューに対応、ハッシュによる物理ファイル重複排除）。写真・書類の一覧にアップロード日時を表示し、写真にはタグを設定・編集できる。アップロードで案件の更新日時を更新する。アップロード実行ユーザーと論理削除実行ユーザーを内部監査情報として保存し、管理者だけが各版の操作ユーザーを確認できる。DBとストレージのバックアップを同一更新単位で作成し、整合性検査、起動時の未確定ファイル隔離、物理削除前の隔離を行う。
- **案件・販売店・担当者・メモ**: 登録・編集・電話番号正規化、各情報のメールアドレス管理（表示されたメールアドレスはメーラー起動）、メモ履歴管理。案件詳細の位置情報はデスクトップでは住所の右側、モバイルでは住所の下に表示する。ユーザー管理では登録日時ではなく更新日時を表示する。案件メモの追加・削除・復元で案件の更新日時を更新する。管理者は削除済みデータを物理削除できる。管理ユーザーの論理削除は管理者だけが実行でき、管理者以外は管理ユーザーを削除できない。viewerは自分のユーザー情報（パスワード）のみ編集できる。
- **クライアント**: Web（PC/モバイルレスポンシブ）、Android、iOS。デスクトップではサイドメニューを除く右側メイン領域を横幅いっぱいに表示し、モバイル幅では案件・ユーザー・販売店などの一覧をカード状の縦並びで表示する。Androidアプリの既定接続先は`https://goma2013.com`として内部固定し、ログイン画面には接続先を表示しない。Androidアプリの検索・案件詳細・ファイル一覧もモバイルWeb版に合わせ、上部タイトルとログアウト、白いカード、青系のアクセント、ラベルと内容の縦並び、詰めた余白で表示する。検索はWeb版と同じ単一検索欄、検索結果件数、カード型の縦並びで表示する。ログイン画面はWeb版と同じ背景色・中央配置・カード型パネル・ブランド表示・入力欄・ボタン余白に揃える。ログイン成功時の本文なし204応答を受け付け、空欄の送信を防止し、401は認証情報または一時的なログイン制限を案内する。案件詳細の「案件情報」「書類」「写真」タブを切り替え、書類・写真タブにカテゴリ別アップロードボタンを配置する。写真カードにはタグを表示し、オンライン時はタグの追加・編集・削除を行える。画像ファイルはサムネイルを表示し、タップでプレビューする。管理メニューはadmin/memberに表示し、管理画面を開く。Androidは起動時に`GET /api/android/latest`でAPK更新を確認し、APKのSHA-256検証後に端末のインストール画面を開く。releaseビルドはGit管理外のkeystoreで署名し、署名済みAPKと同一リリースの`latest.json`を`dist/android-release`へ出力する。
- **モバイルアプリオフライン表示**: Android・iOSは保存済み案件一覧から案件を選択でき、案件詳細では「案件情報」「書類」「写真」のタブを切り替える。オフライン保存は案件IDごとに選択ファイルと期限を管理する。写真タブでは保存済み画像をサムネイル表示し、動画は動画アイコンで表示する。Androidは案件詳細で選択した写真・動画・書類の本体をアプリ専用領域へ保存し、「この案件の選択ファイルを保存」を選択した時に保存期間（日）を1〜3650日で設定する。アプリ起動時に期限切れキャッシュを自動削除する。通信不能時は保存済み案件・ファイルを読み取り専用で表示し、タグを含む写真情報を表示するが、タグ編集を含むアップロード・編集・削除は行わない。ログアウト後も保存期間内のキャッシュは残り、ログイン画面から明示的に全削除できる。
- **共通表示**: Web画面の下部にコピーライト「© 2026 FileManager3」を表示する。

## 3. API・データ
- 主要API: `/api/projects`, `/api/dealers`, `/api/files`, `/api/users`, `/api/me`
- データベース: PostgreSQL（外部キー、トランザクション、インデックス、全文検索）。データは論理削除が基本で、管理者だけが削除済みデータを物理削除できる。`cargo run -- check-integrity` でDB接続、スキーマ、外部キー、ストレージの存在・サイズ・SHA-256、孤立ファイルを検査する。起動時および物理削除時の退避ファイルは `FILE_STORAGE_DIR/.quarantine/` に保持する。

## 4. 起動
HTTPS必須で起動する。初回DB作成時は `ADMIN_PASSWORD` を指定する。
```bash
SECURE_COOKIE=true TLS_CERT_PATH=cert.pem TLS_KEY_PATH=key.pem HOST=0.0.0.0 PORT=3000 cargo run
```
