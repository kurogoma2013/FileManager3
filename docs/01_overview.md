# システム概要

FileManager3は、案件を起点に書類、写真、動画、メモ、販売店、ユーザーを一括管理するLAN対応のローカルWebアプリケーションです。

## 主な機能

- **認証・セッション**: パスワード・パスキー対応。5回失敗で15分ロック、ログアウト時はCookieとDBセッションを同時破棄
- **案件管理**: 単一テキストボックスによるキーワードAND検索、詳細表示、登録・編集・論理削除・復元
- **ファイル管理**: 書類・写真・動画のアップロード、閲覧、移動、印刷、ダウンロード。ハッシュ共通化による重複排除・版履歴管理
- **販売店・担当者・メモ**: 販売店および担当者の管理、案件・販売店へのメモ追加・履歴管理
- **権限管理**: 管理ユーザー（`admin`）、一般ユーザー（`member`）、閲覧ユーザー（`viewer`）の3ロール制御
- **マルチデバイス**: PCおよびモバイルのレスポンシブWeb、Android、iOS
