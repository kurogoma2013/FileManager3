# 権限

ロールは `admin`（管理ユーザー）、`member`（一般ユーザー）、`viewer`（閲覧ユーザー）の 3 種類です。

| 操作 | admin | member | viewer |
| --- | --- | --- | --- |
| 案件検索・詳細閲覧 | 可 | 可 | 可 |
| 案件登録・編集・論理削除 | 可 | 可 | 不可 |
| 案件復元 | 可 | 不可 | 不可 |
| 案件の物理削除（削除済みのみ） | 可 | 不可 | 不可 |
| 書類・写真・動画アップロード | 可 | 可 | 可 |
| 書類・写真・動画の閲覧・ダウンロード・印刷 | 可 | 可 | 可 |
| 写真の移動 | 可 | 可 | 可 |
| 書類の移動 | 可 | 可 | 不可 |
| 書類・写真の論理削除 | 可 | 可 | 不可 |
| 販売店登録・編集・論理削除 | 可 | 可 | 不可 |
| 販売店復元・削除済み一覧 | 可 | 不可 | 不可 |
| 販売店の物理削除（削除済みのみ） | 可 | 不可 | 不可 |
| ユーザー登録・編集・論理削除・パスキー管理 | 可 | 不可 | 不可 |
| 案件メモ閲覧・追加 | 可 | 可 | 可 |
| 販売店メモ閲覧・追加 | 可 | 可 | 不可 |
| 案件/販売店メモ削除 | 可 | 不可 | 不可 |
| 削除済みデータの物理削除 | 可 | 不可 | 不可 |

## 案件単位の権限

`project_permissions` で権限が付与されたユーザーは、対象案件の閲覧・編集およびファイル操作を行えます。

## 管理画面

- `admin`: すべての管理画面（案件・販売店・ユーザー管理、復元操作、仕様書閲覧）を利用可能
- `member`: 案件管理および販売店管理のみ利用可能
- `viewer`: ユーザー管理画面で自分のユーザー情報（パスワード）のみ編集可能。その他の管理画面は利用不可
- 管理ユーザーの論理削除は管理者だけが実行でき、管理者以外は管理ユーザーを削除できない（ログイン中の管理者自身も削除不可）

## viewerの利用範囲

- **利用可能**: 案件検索、案件詳細閲覧、ファイル（書類・写真・動画）の閲覧・アップロード・ダウンロード・印刷、写真の移動、案件メモ閲覧・追加、ユーザー管理画面で自分のユーザー情報（パスワード）の編集
- **利用不可**: 案件情報の変更、書類の移動、ファイルの削除、販売店メモ操作、他ユーザーの編集、ユーザー登録・削除・ロール変更、パスキー管理
