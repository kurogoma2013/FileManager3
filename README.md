# FileManager3

FileManager3 は、案件を起点に書類、写真、メモ、販売店、ユーザーを管理するローカル Web アプリケーションです。
Rust (Axum) と SQLite をバックエンドに採用し、軽量・高速でありながらモダンでプレミアムなUIを提供します。

## ドキュメント

仕様・設計・運用の入口は[要約仕様書](docs/specification.md)に集約しています。画面、API、設定、Android、iOSの詳細仕様へのリンクも同文書にあります。

## Android版

`android/` にネイティブAndroidアプリを配置しています。案件検索、案件詳細、写真・動画・書類の一覧、写真・動画のアップロードに対応します。接続先は証明書を信頼済みにしたHTTPSホスト名を指定してください。

## iOS版

`ios/` にSwiftUI製のiOSアプリを配置しています。案件検索、案件詳細、写真・動画・書類の一覧、写真・動画のアップロードに対応します。詳細は`docs/08_ios.md`を参照してください。
